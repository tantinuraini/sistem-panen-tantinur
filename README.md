# Sistem Pencatatan Hasil Panen
Proyek ini adalah program sederhana berbasis Python untuk menghitung total pendapatan dari hasil panen komoditas pertanian, dilengkapi dengan fitur perhitungan diskon otomatis. Dibuat untuk memenuhi tugas mata kuliah Algoritma dan Pemrograman.

## Cara Menjalankan Program
1. Pastikan Anda memiliki Python yang terinstal di komputer.
2. Unduh atau *clone* repositori ini ke komputer lokal Anda.
3. Buka terminal atau *command prompt*, arahkan ke dalam folder repositori ini.
4. Jalankan perintah berikut: `python panen.py`
